# ESP32-S3 DeepSeek 四驱小车

**固件 1.0.22。** 四驱小车由 ESP32-S3 N16R8 控制。双 INMP441 负责唤醒、收音和左右声源定位。DeepSeek 负责语音转写、理解指令和聊天，播报可选 DeepSeek 或乐鑫本地合成。实际动作、测距和前向急停由车载固件控制。

[接线和供电](docs/WIRING.md) · [配网](#首次配网与语音) · [语音指令](#常用语音指令) · [听声靠近](#听声靠近) · [电机调试](#148-tt-减速电机的点动与排障)

## 烧录

使用 ESP-IDF 6.0.2。将 `PORT` 换成电脑上实际的串口。首次烧录或从 1.0.10 及更早版本升级时，执行完整烧录，写入应用和两个语音资源分区。曾经完整烧录过 1.0.11 或更新版本，且此次只更新应用，使用 `idf.py -p PORT app-flash` 即可。

```bash
git clone git@github.com:qiuhonggang/ESP32-DeepSeek-Rover.git
cd ESP32-DeepSeek-Rover
source /path/to/esp-idf/export.sh
idf.py build
idf.py -p PORT flash monitor
```

烧录保留 NVS 中的 Wi-Fi、API Key、地图和记忆。串口速率为 115200。使用预编译包时，在解压目录执行 `python -m esptool --chip esp32s3 -p PORT -b 460800 write-flash @flash_args`。

## 首次配网与语音

1. 先断开电池和电机动力，按 [接线方案](docs/WIRING.md) 验证供电，用 USB 给主控上电。查看串口打印的 `DeepSeekRover-XXXX` 和控制台口令。
2. 在电脑或手机的 Wi-Fi 设置中加入该热点，再用浏览器打开 `http://192.168.4.1`。首次配置时，热点密码和网页控制台口令均使用串口显示的值。
3. 点「添加 Wi-Fi」，填写能联网的 2.4 GHz Wi-Fi，再填写自己的 DeepSeek API 密钥，点「保存并重启」。电脑或手机接回同一局域网，打开串口显示的 ESP32 IP。网页上「正在同步时钟」消失后可发起 HTTPS 请求。
4. 点「喇叭测试音」确认功放，再点「手动听一句」确认转写和回复。也可以说当前唤醒词，听到小车应答再提问。检测到有效语音后，约 0.42 秒静音结束录音。
5. 任意时候用网页「急停并锁定」停车，手动重新启用后才可下发电机动作。本地识别到唤醒词也会立即暂停车体，语音「停止」在完成 ASR 后再次下达停车。

## 管理多个 Wi-Fi

1. 在「Wi-Fi、DeepSeek 与参数」点「添加 Wi-Fi」，填写 2.4 GHz 网络名称和密码。开放网络勾选「开放网络（无需密码）」。同名网络已保存的密码可留空沿用。
2. 用「上移」「下移」调整优先级，第一项优先。「删除」会从待保存的列表移除该项。列表最多保留 5 项，点「保存并重启」生效。
3. 开机和掉线后，固件都从第一项开始，逐个连接。单项连接或等待 IP 最长约 12 秒，收到失败通知会提前尝试下一项。已经连上的网络持续使用到掉线。
4. 全部尝试失败后，小车开启 `DeepSeekRover-XXXX` 配网热点，并每隔约 15 秒重试一轮。连接成功约 6 秒后，自动开启的配网热点会关闭。列表为空时开机直接开热点。连接成功后，后台会显示当前 Wi-Fi 名称。

## 长按 BOOT 开启配网热点

1. **等小车正常开机，单独按住 BOOT 约 3 秒再松手。** 小车会停车、锁定电机并开启 `DeepSeekRover-XXXX` 热点。手动开启的热点持续到下次重启。
2. 手机加入这个 Wi-Fi，打开 `http://192.168.4.1`。热点使用你保存的「小车配网热点密码」。首次配置时，用串口显示的设备口令连热点。进入网页时，用设备的控制台口令登录。
3. 添加现场可上网的 2.4 GHz Wi-Fi 或手机热点，按需要调整优先级，然后点「保存并重启」。已有 DeepSeek API 密钥时可将密钥输入框留空。再把手机接入同一网络，通过小车的新局域网 IP 打开后台。

出门前可在后台「Wi-Fi、DeepSeek 与参数」设置独立的热点密码。WPA2 密码需要 **8–63 个可打印 ASCII 字符**。密码保存在 NVS，重启后可继续使用。配网热点密码框留空会保留上次保存的值。自动开启的配网热点也使用同一套步骤。

单按 **RST** 会重启主控。按住 **BOOT** 再按 **RST** 用于进入串口下载模式。外出配网用正常开机后长按 **BOOT**。

## 播报与连续对话

在管理页「Wi-Fi、DeepSeek 与参数」里选择「语音合成」，点「保存并重启」。旧设置升级后的默认项是 **DeepSeek（云端）**。

- **DeepSeek（云端）**通过 WebSocket 逐段合成 Flash 已返回的完整短句，收到 PCM 后缓存约 560 ms 再开播。短回复缓存到结尾即可播放。WebSocket 在开播前出错时可回退到 HTTP TTS。 [DeepSeek TTS](https://api-docs.deepseek.com/zh-cn/guides/tts/)
- **乐鑫小乐（本地中文）**在车上逐段合成 16 kHz PCM，开播缓存约 320 ms。「只测 TTS 播报」可在配网热点下测试本地合成。语音识别和聊天仍使用云端。 [乐鑫本地 TTS](https://docs.espressif.com/projects/esp-sr/zh_CN/latest/esp32s3/speech_synthesis/readme.html)
- **插话和追问。** 播报时可以直接说下一句，固件先从双麦收音中判断持续的人声，再短暂停播确认。语句中间可以有短停顿。确认后转入新一轮收音，并保留开头的人声。如果没有确认到有人在说话，会接着播原来的音频。播完后约有 **8 秒**可以直接追问。说「不聊了」、点「停止语音」、等待超时或掉线会结束当前对话。
- **听起来卡顿时**，先用网页「测试流式对话和播报」。在「唤醒与回声」查看缓冲耗尽次数、插话核验暂停次数、I²S 读写错误和播报结果。缓冲耗尽表示音频供给曾跟不上。核验次数增加表示播报为确认人声短暂停过。
- **对话数据。** ASR 在说完后上传 WAV 并返回转写。普通聊天使用 Flash SSE，按问题附带设备读数和地图。开启历史后，NVS 保存最近 12 轮完整播完的对话，最多发送最近 3 轮。网页可查看实际合成路径、各阶段耗时和 Flash Token 用量。控制台在可信局域网或配网热点访问，云端连接校验证书。 [DeepSeek ASR](https://api-docs.deepseek.com/zh-cn/guides/asr/) · [Flash SSE](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)

## 选择本地唤醒词

进入网页「Wi-Fi、DeepSeek 与参数」，在「本地唤醒词」里任选一个，再点「保存并重启」。启动后「唤醒与回声」会显示当前生效的选项。固件只启用所选的一个模型。更换唤醒词时，密码和 API Key 字段留空即可。

唤醒后会轮换播放「在呢」「我在呀」「我听着呢」「你好呀」。唤醒和部分短确认语来自固件内置的 Kokoro 音频。 [Kokoro 模型与许可](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh)

| 选项 | 唤醒词 |
| --- | --- |
| 原有 4 个 | 嗨小象、嗨喵喵、你好小智、嗨，乐鑫 |
| 新增 WakeNet9 | 小鸭小鸭、小鹿小鹿、小龙小龙、小冰小冰、小珈小珈、嗨小欧、小酥肉、你好星宝、你好东东、你好小安、喵喵同学、小美同学 |
| 新增 WakeNet10 | 双儿、涂涂你好、豆包豆包、DeepSeek |

先在车停稳且喇叭安静时试念完整唤醒词，再在平常使用的位置试。孩子真实发音的唤醒率和误触发需用装好的车验证。 [乐鑫预置词列表](https://github.com/espressif/esp-sr/blob/master/wakeword_list.md)

## 网页调试

- **语音与对话调试**可分别测试 ASR、Flash、TTS。「测试流式对话和播报」验证从 Flash 到喇叭的链路。「只测语音意图（不动电机）」可输入转写文字，查看 Flash 转成了哪个动作。「手动听一句」测试完整的语音问答。音量滑块松手即生效并保存。
- **语音动作没执行时**，先看后台转写。把同一句填进「只测语音意图（不动电机）」可以检查模型是否听懂意图。识别成动作后，再看电机锁定、前向测距和「上次指令」，确认固件是拦截了动作还是已发完电机脉冲。
- **双麦测试**实时显示左右电平和声源方位估计，**本轮硬件读数**显示用于当前问答的方位、车头测距和速度档。网页文字测试没有当轮话音方位，适合单独验证测距。
- **超声波测距调试**显示实时距离、回波脉宽、采样编号、急停阈值和避障状态，保留最近 12 次网页读取值。
- **电机调试**显示底盘锁定状态和最近一次动作的结果、实际采用的 PWM 及时长。先架空四轮，再启用电机，按正向或反向点动指定轮。点动和整车短动仍由固件限制时长和速度。按「急停并锁定」可立即取消动作。

### 1:48 TT 减速电机的点动与排障

- **先用实测起点复现。** 四轮架空，纸板正对超声波，网页打开「电机调试」，用正向 **PWM 145、240 ms** 逐轮点动。1.0.17 把这组值设为网页默认值；升级后刷新已打开的网页。全车配置的最大 PWM 仍然有效，反向仍限 115。1:48 表示齿轮减速比。当前的 **1 kHz** 来自这辆车的架空实测，装车后的起步表现还受电源和负载影响。
- **整车短动与单轮共用网页参数。** 短前进、短后退、短左转、短右转会发送页面显示的 PWM 和时长。短后退仍受固件的 PWM 115 上限保护。逐只点正向，轮胎顶部应朝车头。若只有左前正确，在当前极性基础上反转右前、左后、右后；后轮左右互换与转向极性分别设置。
- **辨别点动声。** 网页的电机按钮不会主动播放喇叭测试音。若声音来自电机，可在「测距、电机和声音」打开「降低电机啸叫」，保存后架空复测。该选项使用 24 kHz 慢衰减 PWM；原来的 1 kHz 模式可随时恢复。如果单轮能转而四轮只响，检查整车指令是否中断，以及同时起步时两块驱动板各自 VCC 对 GND 的电压。供电和齿轮的机械噪声须分别排查。[DRV8833 驱动模式，表 2](https://www.ti.com/lit/ds/symlink/drv8833.pdf#page=9)
- **看“上次指令”。** 数字依次是实际采用的 PWM、控制任务的运行时间/请求限幅后的时长。显示“脉冲已发完”代表固件走完这段输出；轮速和转角需要观察实物。旧版默认 105、180 ms，这辆车曾出现仅有声音、轮子没动。点动刹车约 100 ms，等上一次结束再点下一次。
- **设置前向急停距离。** 在「超声波测距调试 → 前向急停距离 → 修改」输入 10–100 cm 的整数，点「保存并重启」。新设备默认 10 cm；升级沿用已保存的阈值。有效读数小于或等于设定值时拦截前进。连续两次读到“设定值 + 5 cm”或更远才解除拦截。10 cm 是触发阈值，落地后的停车距离还取决于车速和地面。
- **若显示中断**，按当次停止原因排查。单轮正向点动开始后，若上一次有效距离至少为急停距离加 5 cm，允许一次未收到完整回波，且上次有效读数最多使用 170 ms。连续第二次无回波、收到超出有效范围的脉宽、采样过期或测到障碍时都会中断。启动点动和整车前进仍要求当前回波有效。观察到电机一启动测距就失效时，检查 HC-SR04 的供电、共地和探头前方，电机大电流回路与测距线分开走。
- **若脉冲发完但只有嗡声**，先停下，核对实际 PWM 和时长。断电查看轮子有无卡住、焊点和接插件是否松动；再量驱动板自身 VCC/GND 在点动时有无明显压降。普通万用表可能漏掉短时跌落。不要按住轮子测试，也不要往仍连着驱动板的 OUT 端外加电压。后板 A 接右后、B 接左后时启用「后轮左右互换」，然后按实际轮位调极性。

单轮堵转识别需要电流或轮速反馈。DRV8833 具体的硬件限流取决于模块的采样电阻接法。 [接线与电机保护说明](docs/WIRING.md)

## 四轮校准与建图

建图按 PWM 时间估算位移和转角，打滑会积累误差。单颗前向超声波只覆盖车头的一束距离。请在平坦、封闭、回波清晰的小场地低速验证。

1. 架空四轮，把挡板放在超声波前约 40–80 cm，确认网页测距有效和车头方向。启用电机，按「左前、右前、左后、右后」逐个点动，确认正确轮子转动，借助四轮极性选项统一前进方向。
2. 放到平地，用胶带标记固定起点和初始朝向。用尺子量「标定走一格」的实际位移。默认格边长 25 cm，调整 PWM 和前进时间，使实际位移接近一格。分别标定左转、右转按键的 90° 时间，避免默认毫秒值被当成实测参数。
3. 把车放回起点。首次选「清空并设起点」，已有地图时选「重新对齐起点」，需复现原位置、朝向以及地面条件。将地图的「上」理解为你设置的方向。
4. 点「开始扫描建图」或语音说「开始建图」。小车在站点按四个方向转身测距，标记有足够前向余量的网格，在确认可通行的网格中规划下一步。默认要求移动前前方距离至少达到 **一格长度 + 急停距离 + 6 cm**。每步行驶中另外持续检测急停距离。路线前方变得不可通行时，车在当前格重算路线；若在移动途中急停，则需要回到原点重新对齐。
5. 停稳后可点击已知空闲格导航，或者把当前格命名为「客厅」等地点。用网页或语音「返回起点」「去客厅」开始导航，云端语音命令也会校验地图和电机状态。地图须点「保存地图」才会跨重启保留，命名地点时会同时保存。重启或手动点动后，车身位姿需要重新对齐。

地图中心是起点 `(10,10)`，行列从 0 到 20。默认 25 cm 时理论栅格覆盖约 5.25 × 5.25 m，实际覆盖取决于超声波回波、转角和轮胎打滑。单次运行最多行驶 32 格或 135 秒。可在地图上查看估计位置及前方测距。

## 常用语音指令

说网页选定的唤醒词后，可以用自己的说法发出指令。下一轮在追问窗口内可以省略唤醒词。

| 想做什么 | 可以这样说 |
| --- | --- |
| 前进 | 往前、再往前一点儿、向前挪一小步 |
| 后退 | 往后、帮我往后退一点、倒一下车 |
| 左右转 | 左转、朝右边转一下、把车头往左摆一点 |
| 停车 | 停车、停下来、别动 |
| 靠近说话的位置 | 过来、开到我这边来、来我这里 |
| 按双麦方向转 | 朝我转一下 |
| 扭动 | 扭一扭、左右摇一下 |
| 自动扫描 | 开始建图、开始巡游 |
| 地点操作 | 把这里记为客厅、去客厅、返回起点 |
| 保存一条偏好 | 记住我喜欢简短的回答 |
| 问车况 | 我在你哪边？前面有什么挡着吗？ |
| 音量 | 大声一点、小声一点、我说，音量调到 2%、静音、恢复声音 |
| 速度档 | 走慢一点、开快一点、恢复正常速度 |
| 带速度档的动作 | 慢慢前进、后退快一点、慢一点左转 |
| 停车并锁轮 | 急停、关闭电机 |

ASR 转写后，Flash 从固件规定的动作中选择一个适合本轮请求的动作。固件验证动作并检查电机启用状态、测距和动作时长。普通前后和转向执行一次短动作。「停车」「别动」「急停」等明确短语，以及音量、速度档和结束对话的常用说法，由固件在转写后直接处理。遇到「如果往前会怎样」「我刚才说了往后」等问句或转述时，小车按对话处理。命名地点和保存偏好使用说话人自己给出的内容。语音行驶前由成人在网页启用电机。

每轮问答会把当前话音估计的左右、中线或未知方位，以及最新的车头超声波读数、电机状态、音量和语音速度档交给 Flash。网页的「本轮硬件读数」会显示用于这轮的方向和距离。双麦只能估计左右，声源在中线时分不出前后。超声波读数表示车头前方的反射物，能否把它视为人的距离取决于人是否站在车头正前方。

音量会保存，范围为 0–75%。静音后说「恢复声音」可回到 28%。「走慢一点」切换后续语音速度档，重启恢复正常档。「慢慢前进」只影响这一条。慢、正常、快分别请求 PWM 130、145、160，受网页最大 PWM 限制，后退仍限 115。要在不同档位看到差别，设定的上限也要覆盖对应档位。

对话角色是智能小车，用自然、简短的普通话回答，结合当前车况说明动作结果，和小朋友说话时也保持清楚易懂。保存记忆以播报完成为准，被插话的回复不会写入对话记录。关闭历史开关停止写入和传送历史轮次，单独保存的偏好及网页资料仍作为上下文。网页的「清空历史和语音偏好」清理这两项，网页资料独立编辑。

### 听声靠近

说「过来」时，小车使用这轮收音得到的左右方位。请站在小车正前方或左前、右前侧说话。听出左右后，小车按标定时间朝对应侧转约 45°，停一下并重新测距。双麦听到中线时，若你确实站在正前方，可以说「我在车头前面，过来」。方向不清楚时小车会停在原地等你重说。

前方有足够空间时，小车沿当前车头方向持续前进。遇到障碍、回波丢失、超过单次 **6 秒**时限、开始收听新一句、急停、电机锁定或掉线时结束。停车距离阈值取 **25 cm** 和网页「前向急停距离」里的较大值。前方超声波测的是反射物，声源方位只在发出指令时估计一次，行驶中无法跟踪走动的人。首次落地验证时让成人在旁，保持网页「急停并锁定」可用。[测距和接线验收](docs/WIRING.md#桌面验收)
