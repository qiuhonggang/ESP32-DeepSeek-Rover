# ESP32-S3 DeepSeek 四驱小车

ESP32-S3 N16R8 是唯一车载控制器，双 INMP441 负责唤醒、语音输入和左右声源定位，MAX98357A 驱动 3070 喇叭。ESP32 通过 HTTPS 直接访问 DeepSeek ASR、Flash 和 TTS。四路电机控制、声学前处理、测距急停、网格建图和寻路都在车上完成。

**当前源码版本 1.0.8。** 小车可记住 **5 个 2.4 GHz Wi-Fi**，按列表优先级自动连接。开机后单独长按 **BOOT 约 3 秒**也可以随时开启配网热点。 [管理多个 Wi-Fi](#管理多个-wi-fi) · [长按 BOOT 开启配网热点](#长按-boot-开启配网热点)

| 功能 | 当前实现 |
| --- | --- |
| 配网 | 保存最多 5 个 Wi-Fi，网页添加、删除和排序。全部失败后自动开热点，也可长按 BOOT 手动开启 |
| 本地唤醒 | ESP-SR WakeNet9 / WakeNet10 共 20 个预置词，默认「嗨小象」。网页选词，唤醒后轮换播放四条本地应答 |
| 双麦和插话 | 双声道采样、左右声源定位、I²S 回声抵消。播报时说当前唤醒词可打断 |
| 云端语音 | 16 kHz 单声道 WAV → DeepSeek ASR → `deepseek-flash` SSE → DeepSeek TTS WebSocket。边接收边播，云端语音约 0.89 倍速 |
| 硬件问答 | 本轮双麦方位、车头测距、电机状态、音量和语音速度档随问答送给 Flash |
| 语音控制 | 音量、静音、前进后退、转向、慢／正常／快、停车和锁定电机 |
| 记忆 | 使用 NVS 保存 12 轮已播完对话，最近 6 轮作为上下文。给 4 岁小朋友的普通话短句，支持语音保存的偏好和网页资料 |
| 四驱 | 两块 DRV8833 驱动四个通道，左右两侧差速。网页可单轮点动、调四轮极性、架空测试 |
| 建图与寻路 | 单颗前向超声波配合停转扫描，21×21 占据网格，BFS 绕行、已知区域导航、命名地点、返回起点 |
| 本地保护 | 开机锁电机，动作限时，前向测距过近或失效停车。运行中断导致位姿未知时停止导航 |

**导航属于实验性低速功能。** 车靠定时 PWM 估算单格位移和 90° 转角，转向时的打滑、地面、负载和电压都会让估计位置漂移。单颗超声波只能测朝向的一束距离，侧面、后方及地面落差超出覆盖范围。地图适合在平坦、封闭、有清晰回波的小场地验证。丢回波会拦截前进，开阔处可能因此停下。 [HC-SR04 资料](https://cdn.sparkfun.com/datasheets/Sensors/Proximity/HCSR04.pdf) · [机器人里程计说明](https://docs.nav2.org/rolling/configuration_and_development/first_time_robot_setup_guide/odom/setup_odom/)

## 烧录

源码用 ESP-IDF 6.0.2 编译。**首次烧录请刷全部四段**，包括程序、分区表、bootloader 和 WakeNet 模型。配置、地图和记忆存放在独立 NVS 分区。当前版本可直接从源码构建。

如果手头有对应版本的预编译烧录包，可以解压后进入烧录目录。将 `PORT` 替换为你的串口，例如 `/dev/cu.usbmodemXXXX` 或 `/dev/cu.usbserial-XXXX`。

```bash
python -m pip install "esptool>=5,<6"
python -m esptool --chip esp32s3 -p PORT -b 460800 write-flash @flash_args
```

从 GitHub 获取源码并编译。已有本地项目时，直接在项目目录中编译。

```bash
git clone git@github.com:qiuhonggang/ESP32-DeepSeek-Rover.git
cd ESP32-DeepSeek-Rover
source /path/to/esp-idf/export.sh
idf.py build
idf.py -p PORT flash monitor
```

**从 1.0.0 或 1.0.1 更新到 1.0.2** 时，用新烧录包的四段完整写入，包括扩容后的分区表和新 `srmodels.bin`。应用、模型和 NVS 的起始偏移沿用旧版，模型分区从 3 MiB 扩为 8 MiB。用包内命令分段写入并保留 NVS，已有的唤醒词设置、Wi-Fi、DeepSeek Key、地图和对话记忆均可沿用。

已完整烧录 1.0.2 的分区表和模型的设备，可以在编译后用 `idf.py -p PORT app-flash` 更新到 1.0.8，并保留 NVS 中的设置和记忆。旧版保存的单个 Wi-Fi 会自动迁移为列表第一项，原有密码可继续使用。

串口速率为 115200。若开发板有 USB 和 UART 两个接口，首次接线可选带 USB 转串口的 UART 接口读日志，或使用板上 USB Serial/JTAG 口。串口显示 `WakeNet ready: 嗨小象 (...)` 或所选词的名称，代表模型初始化完成。 [ESP32-S3 DevKitC 手册](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/user_guide_v1.1.html) · [WakeNet 文档](https://docs.espressif.com/projects/esp-sr/en/latest/esp32s3/wake_word_engine/README.html)

## 首次配网与语音

1. 先断开电池和电机动力，按 [接线方案](WIRING.md) 验证供电，用 USB 给主控上电。查看串口打印的 `DeepSeekRover-XXXX` 和控制台口令。
2. 在电脑或手机的 Wi-Fi 设置中加入该热点，再用浏览器打开 `http://192.168.4.1`。首次配置时，热点密码和网页控制台口令均使用串口显示的值。
3. 点「添加 Wi-Fi」，填写能联网的 2.4 GHz Wi-Fi，再填写自己的 DeepSeek API 密钥，点「保存并重启」。电脑或手机接回同一局域网，打开串口显示的 ESP32 IP。网页上「正在同步时钟」消失后可发起 HTTPS 请求。
4. 点「喇叭测试音」确认功放，再点「手动听一句」确认转写和回复。也可以说当前唤醒词，听到小车应答再提问。检测到有效语音后，约 0.42 秒静音结束录音。
5. 任意时候用网页「急停并锁定」停车，手动重新启用后才可下发电机动作。本地识别到唤醒词也会立即暂停车体，语音「停止」在完成 ASR 后再次下达停车。

## 管理多个 Wi-Fi

1. 在「Wi-Fi、DeepSeek 与参数」点「添加 Wi-Fi」，填写 2.4 GHz 网络名称和密码。开放网络勾选「开放网络（无需密码）」。同名网络已保存的密码可留空沿用。
2. 用「上移」「下移」调整优先级，第一项优先。「删除」会从待保存的列表移除该项。列表最多保留 5 项，点「保存并重启」生效。
3. 开机和掉线后，固件都从第一项开始，逐个连接。单项连接或等待 IP 最长约 12 秒，收到失败通知会提前尝试下一项。已经连上的网络持续使用到掉线。
4. 全部尝试失败后，小车开启 `DeepSeekRover-XXXX` 配网热点，并每隔约 15 秒重试一轮。连接成功约 6 秒后，自动开启的配网热点会关闭。列表为空时开机直接开热点。连接成功后，后台会显示当前 Wi-Fi 名称。

## 长按 BOOT 开启配网热点

1. **等小车正常开机，单独按住 BOOT 约 3 秒再松手。** 小车会停车、锁定电机并开启 `DeepSeekRover-XXXX` 热点。手动开启的热点持续到下次重启。
2. 手机加入这个 Wi-Fi，打开 `http://192.168.4.1`。热点使用你保存的「小车配网热点密码」。首次配置时，用串口显示的设备口令连热点。进入网页时，用设备的控制台口令登录。
3. 添加现场可上网的 2.4 GHz Wi-Fi 或手机热点，按需要调整优先级，然后点「保存并重启」。已有 DeepSeek API 密钥时可将密钥输入框留空。再把手机接入同一网络，通过小车的新局域网 IP 打开后台。

出门前可在后台「Wi-Fi、DeepSeek 与参数」设置独立的热点密码。WPA2 密码需要 **8–63 个可打印 ASCII 字符**。密码保存在 NVS，重启后可继续使用。配网热点密码框留空会保留上次保存的值。自动开启的配网热点也使用同一套步骤。

单按 **RST** 会重启主控。按住 **BOOT** 再按 **RST** 用于进入串口下载模式。外出配网用正常开机后长按 **BOOT**。

## 对话链路与数据

管理网页使用 HTTP，可通过配网热点或可信局域网访问。固件使用 HTTPS/WSS 和证书校验连接 `api.deepseek.com`。DeepSeek API 密钥写入设备 NVS。唤醒后的录音送给 ASR，转写、本轮硬件读数及启用的对话上下文送给 Flash，回复文本送给 TTS。 [DeepSeek ASR](https://api-docs.deepseek.com/zh-cn/guides/asr/) · [Flash JSON 输出](https://api-docs.deepseek.com/zh-cn/guides/json_mode/) · [DeepSeek TTS](https://api-docs.deepseek.com/zh-cn/guides/tts/)

DeepSeek ASR 接收完整 WAV 后返回一次转写。普通对话把 Flash SSE 的文本增量分段送给 TTS WebSocket，边接收 PCM 边排队播报。流式 TTS 若在出声前失败，会用已生成的回复改走 HTTP TTS。动作确认走完整的 Flash JSON 校验流程。官方 TTS 没有语速参数，固件将云端播报放慢至约 0.89 倍，音高也会略降。 [Flash SSE](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/) · [TTS WebSocket](https://api-docs.deepseek.com/zh-cn/guides/tts/#websocket-流式合成)

## 选择本地唤醒词

进入网页「Wi-Fi、DeepSeek 与参数」，在「本地唤醒词」里任选一个，再点「保存并重启」。启动后「唤醒与回声」会显示当前生效的选项。固件只启用所选的一个模型。更换唤醒词时，密码和 API Key 字段留空即可。

唤醒后会轮换播放四条简短的本地应答，听到应答再开口。播报途中，可以说当前唤醒词打断，也可以点网页「停止语音」。打断开关位于「Wi-Fi、DeepSeek 与参数」。后台会记录最近一次播报是完整播完、手动停止、唤醒词打断或遇到异常。

本地应答为「在呢」「我在呀」「我听着呢」「你好呀」，用 Kokoro v1.1-zh 的 `zf_001` 音色离线合成。仓库内的 `main/cues/` 保存四条 16 kHz、16 bit 单声道 PCM，编译时直接嵌入固件。 [Kokoro 模型与许可](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh)

| 选项 | 唤醒词 |
| --- | --- |
| 原有 4 个 | 嗨小象、嗨喵喵、你好小智、嗨，乐鑫 |
| 新增 WakeNet9 | 小鸭小鸭、小鹿小鹿、小龙小龙、小冰小冰、小珈小珈、嗨小欧、小酥肉、你好星宝、你好东东、你好小安、喵喵同学、小美同学 |
| 新增 WakeNet10 | 双儿、涂涂你好、豆包豆包、DeepSeek |

先在车停稳且喇叭安静时试念完整唤醒词，再在平常使用的位置试。孩子真实发音的唤醒率和误触发需用装好的车验证。 [乐鑫预置词列表](https://github.com/espressif/esp-sr/blob/master/wakeword_list.md)

## 网页调试

- **语音与对话调试**可分别测试 ASR、Flash、TTS，也可用「测试流式对话和播报」验证 Flash 到喇叭的链路。网页显示首段文字、完整文字和首批音频的耗时，计时从 Flash 请求前开始。文字测试隔离对话记忆和车体动作。「手动听一句」走完整语音会话。音量滑块松手即生效并保存。
- **双麦测试**实时显示左右电平和声源方位估计，**本轮硬件读数**显示用于当前问答的方位、车头测距和速度档。网页文字测试没有当轮话音方位，适合单独验证测距。
- **超声波测距调试**显示实时距离、回波脉宽、采样编号、急停阈值和避障状态，保留最近 12 次网页读取值。
- **电机调试**显示底盘锁定状态和最近一次动作的结果、实际采用的 PWM 及时长。先架空四轮，再启用电机，按正向或反向点动指定轮。点动和整车短动仍由固件限制时长和速度。按「急停并锁定」可立即取消动作。

单轮堵转识别需要电流或轮速反馈。DRV8833 具体的硬件限流取决于模块的采样电阻接法。 [接线与电机保护说明](WIRING.md)

## 四轮校准与建图

1. 架空四轮，把挡板放在超声波前约 40–80 cm，确认网页测距有效和车头方向。启用电机，按「左前、右前、左后、右后」逐个点动，确认正确轮子转动，借助四轮极性选项统一前进方向。
2. 放到平地，用胶带标记固定起点和初始朝向。用尺子量「标定走一格」的实际位移。默认格边长 25 cm，调整 PWM 和前进时间，使实际位移接近一格。分别标定左转、右转按键的 90° 时间，避免默认毫秒值被当成实测参数。
3. 把车放回起点。首次选「清空并设起点」，已有地图时选「重新对齐起点」，需复现原位置、朝向以及地面条件。将地图的「上」理解为你设置的方向。
4. 点「开始扫描建图」或语音说「开始建图」。小车在站点按四个方向转身测距，标记有足够前向余量的网格，在确认可通行的网格中规划下一步。默认要求移动前前方距离至少达到 **一格长度 + 急停距离 + 6 cm**。每步行驶中另外持续检测急停距离。路线前方变得不可通行时，车在当前格重算路线；若在移动途中急停，则需要回到原点重新对齐。
5. 停稳后可点击已知空闲格导航，或者把当前格命名为「客厅」等地点。用网页或语音「返回起点」「去客厅」开始导航，云端语音命令也会校验地图和电机状态。地图须点「保存地图」才会跨重启保留，命名地点时会同时保存。重启或手动点动后，车身位姿需要重新对齐。

地图中心是起点 `(10,10)`，行列从 0 到 20。默认 25 cm 时理论栅格覆盖约 5.25 × 5.25 m，实际覆盖取决于超声波回波、转角和轮胎打滑。单次运行最多行驶 32 格或 135 秒。可在地图上查看估计位置及前方测距。

## 常用语音指令

每轮先说网页上选定的唤醒词，默认「嗨小象」。稍停后说一整句，动作短句以表内示例为准。

| 想做什么 | 可以这样说 |
| --- | --- |
| 行走 | 前进、后退、左转、右转、扭一扭 |
| 按双麦方向转 | 朝我转一下 |
| 停车 | 停止、别动 |
| 自动扫描 | 开始建图、开始巡游 |
| 地点操作 | 把这里记为客厅、去客厅、返回起点 |
| 保存一条偏好 | 记住我喜欢简短的回答 |
| 普通对话 | 介绍一下你自己 |
| 问车身周围 | 我在你哪边？我离你多远？ |
| 音量 | 大声一点、小声一点、音量调到百分之三十、静音、恢复声音 |
| 速度档 | 走慢一点、开快一点、恢复正常速度 |
| 带速度档的动作 | 慢慢前进、后退快一点、慢一点左转 |
| 停车并锁轮 | 急停、关闭电机 |

含否定、转述或连续多个动作的句子按对话处理。可执行的行驶、导航等动作需要匹配当前语音短句和 Flash 返回的动作名，超过 12 秒的动作回复作废。小车直接处理语音停车、锁定、音量和速度档，在电机未启用或前进被拦截时会直接说明原因。后退限于短距离点动。唤醒词会先停下当前运动，单纯问答也会暂停巡游。

每轮问答会把当前话音估计的左右、中线或未知方位，以及最新的车头超声波读数、电机状态、音量和语音速度档交给 Flash。网页的「本轮硬件读数」会显示用于这轮的方向和距离。双麦只能估计左右，声源在中线时分不出前后。超声波读数表示车头前方的反射物，能否把它视为人的距离取决于人是否站在车头正前方。

音量可通过语音立即修改并保存，范围为 0–75%。调到 0 后可继续使用唤醒词说「恢复声音」，回到默认音量 28%。单独说「走慢一点」调整接下来的语音动作档位，重启恢复正常档。说「慢慢前进」只调整这一条指令。速度与动作时长受后台设置和底盘保护限制。电机由成人在网页启用，语音可以停止和锁定。

对话默认面向 4 岁小朋友。小车平时用一两句简单、温柔的普通话回答，一次只问一个问题，故障提示也用孩子能听懂的说法。保存记忆以播报完成为准，被插话的回复不会写入对话记录。关闭历史开关停止写入和传送历史轮次，单独保存的偏好及网页资料仍作为上下文。网页的「清空历史和语音偏好」清理这两项，网页资料独立编辑。
